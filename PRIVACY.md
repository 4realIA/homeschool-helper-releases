# Homeschool Helper privacy policy

Last updated: November 19, 2026

Homeschool Helper is a practice app for homeschool families, published by Dmd-Dev. It was built so that a family's information stays in the family's home.

## What the app keeps

The app keeps everything it needs on the computer or tablet it is installed on:

- each child's first name (or nickname), grade and picture choice
- practice results: which activities were played, which answers were right or missed, stars earned and time spent
- spelling lists, math sets and the memory verse a parent sets up
- the parent PIN, stored only as a one-way hash, never as the PIN itself

There are no accounts, no sign-in, no email addresses and no payment details.

## What the app sends

Nothing. Homeschool Helper does not collect, upload, sell or share any information. It has no analytics, no advertising, no tracking and no third-party services.

- The **Microsoft Store** copy of the app makes no network connections. The Store installs its updates.
- The copy downloaded from this page checks this page for new versions. That check downloads a small version file and sends nothing about the family or the children.
- Read-aloud uses the voices built into the device (Windows, macOS or iPadOS).

The operating system, the Microsoft Store and the web view the app runs in (Microsoft Edge WebView2 on Windows, WebKit on Mac and iPad) are covered by Microsoft's and Apple's own privacy statements.

## Children

The app is meant to be set up by a parent and used by children with a parent's oversight. Because no information leaves the device, the publisher never receives any information about children.

## Removing information

A parent can delete a child and all of that child's progress in 🔒 Parent → Children. Uninstalling the Microsoft Store copy removes its data from the device; the uninstaller for the downloaded copy offers to remove it.

## Changes

If this policy changes, the new version will be posted on this page with a new date.
